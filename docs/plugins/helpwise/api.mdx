## Contacts

### create

`contacts.create`

Create a new contact

**Risk:** `write`

```ts
await corsair.helpwise.api.contacts.create({
	firstname: 'Alex',
	emails: ['alex@example.com'],
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `firstname` | `string` | Yes | — |
| `lastname` | `string` | No | — |
| `company` | `string` | No | — |
| `jobTitle` | `string` | No | — |
| `emails` | `string[]` | No | — |
| `phones` | `object[]` | No | — |
| `customFields` | `object[]` | No | — |

<AccordionGroup>
<Accordion title="phones full type">

```ts

  phoneTxt: string,
  phoneNo: string,
  type?: string
}[]
```
</Accordion>

<Accordion title="customFields full type">

```ts

  id: number,
  value: string,
  name?: string
}[]
```
</Accordion>
</AccordionGroup>



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `number` | Yes | — |

| `company` | `string \| null` | No | — |
| `jobTitle` | `string \| null` | No | — |
