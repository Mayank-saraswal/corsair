Use **Simla.com** through Corsair: one client, typed API calls.

Configure an API key in Corsair and set `subdomain` to the account-specific host prefix. Requests use `X-API-KEY` and `https://{subdomain}.simla.com/api/v5/`. POST nested values are JSON strings inside form-urlencoded bodies.

List operations pass through the documented `page`/`limit` pagination metadata; cursor-based operations accept their documented cursor parameter. The account is limited to 10 requests per second per IP (40 for telephony); the provider may respond with 503 when the limit is exceeded.

Binary upload expects base64 in `body`; binary download responses are `{ kind: 'binary', contentType, base64 }` and the client enforces a 20 MiB safety limit.

The plugin excludes the 27 provider-hosted integration-module callback/configuration routes and all inbound webhook receiving/management (outside issue #2408).

**What you get:**

- 230 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/simlacom better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/simlacom better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/simlacom better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/simlacom better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { simlacom } from '@corsair-dev/simlacom';

export const corsair = createCorsair({
	plugins: [
		simlacom({
			subdomain: 'demo',
		}),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Simla.com API key before the first call: `pnpm corsair setup --plugin=simlacom --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

Configure the instance subdomain used by the Simla.com API host.

```ts
simlacom({
	subdomain: 'demo',
})
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'simlacom',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Read the available Simla.com API versions**

```ts
const tenant = corsair.withTenant('acme');
await tenant.simlacom.api.api.apiVersions.get({});
```


**Create a customer record**

```ts
const tenant = corsair.withTenant('acme');
await tenant.simlacom.api.customers.create.post({});
```


See the full list on the [API](/plugins/simlacom/api) page.
