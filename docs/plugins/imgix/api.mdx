## Assets

### addFromOrigin

`assets.addFromOrigin`

Queue an existing origin asset to be indexed into the Imgix Asset Manager

**Risk:** `write`

```ts
await corsair.imgix.api.assets.addFromOrigin({ source_id: 'src_1234567890abcdef', origin_path: 'products/hero.jpg' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `source_id` | `string` | Yes | — |
| `origin_path` | `string` | Yes | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `data` | `object` | No | — |
| `jsonapi` | `object` | No | — |

<AccordionGroup>
<Accordion title="data full type">

```ts
{
  id?: string,
  type?: string,
  attributes?: Record<string, any>
}
```

## Generations

### createVideo

`generations.createVideo`

Transform a static image into a video using AI motion generation (consumes AI credits)

**Risk:** `destructive`

```ts
await corsair.imgix.api.generations.createVideo({ prompt: 'Slow cinematic pan across a mountain vista', source: 'https://images.example.com/mountain.jpg' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `prompt` | `string` | Yes | — |
| `source` | `string` | Yes | — |
| `duration` | `number` | No | — |
| `aspect_ratio` | `string` | No | — |

Asynchronously transforms an image into a video using AI motion generation. Poll generations.getVideoJob with the returned job_id until status is ready.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `job_id` | `string` | Yes | — |
| `status` | `pending \| processing \| ready \| errored \| string` | Yes | — |
| `created_at` | `string` | No | — |
