---
title: "Trustpilot database"
sidebarTitle: "Database"
description: "The Trustpilot plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Trustpilot. To read its data, call the [API operations](/plugins/trustpilot/api), which return what Trustpilot has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
