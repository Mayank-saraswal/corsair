Use **Thinkific** through Corsair: one client, typed API calls.

This plugin uses the documented Admin API v1 at https://api.thinkific.com/api/public/v1. Configure an API key and store the Thinkific site subdomain as the account tenant_external_id. It sends X-Auth-API-Key and X-Auth-Subdomain headers. Admin API v2 is not verified. Webhook management/receivers and OAuth-only Site Scripts operations are excluded.

**What you get:**

- 73 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/thinkific better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/thinkific better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/thinkific better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/thinkific better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { thinkific } from '@corsair-dev/thinkific';

export const corsair = createCorsair({
	plugins: [
		thinkific(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Thinkific API key before the first call: `pnpm corsair setup --plugin=thinkific --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
thinkific()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'thinkific',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List Thinkific courses**

```ts
const tenant = corsair.withTenant('acme');
await tenant.thinkific.api.courses.list({
	query: { page: 1, limit: 25 },
});
```


**Create a Thinkific user**

```ts
const tenant = corsair.withTenant('acme');
await tenant.thinkific.api.users.create({
	body: { first_name: 'Sample', last_name: 'Learner', email: 'learner@example.com' },
});
```


See the full list on the [API](/plugins/thinkific/api) page.
