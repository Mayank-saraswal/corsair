## Bundles

### createEnrollment

`bundles.createEnrollment`

Create an Enrollment in a Bundle of Courses

**Risk:** `write`

```ts
await corsair.thinkific.api.bundles.createEnrollment({ path: {"id":1}, body: {"user_id":1} });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `path` | `object` | Yes | — |
| `body` | `object` | No | — |

Thinkific documents both 201 synchronous and 202 asynchronous creation responses without a response body schema; this operation validates an empty response rather than inventing a job payload.

<AccordionGroup>
<Accordion title="path full type">

```ts
{
  id: number
}
```
</Accordion>

<Accordion title="body full type">

```ts
{
  user_id: number,
  activated_at?: string,
  expiry_date?: string
}
```
</Accordion>
</AccordionGroup>



**Output:** `undefined`
